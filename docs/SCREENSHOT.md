# Adding the screenshot

1. `pnpm dev`, open http://localhost:3000, wait until the top bar shows every feed live and the feed has signals.
2. Set the window to 1440 px wide, capture the page from the top bar through the chart strip, save it as `docs/screenshot.png`.
3. In `README.md`, change the image path from `docs/screenshot-placeholder.svg` to `docs/screenshot.png` and delete the placeholder.

Do not stage or edit the capture beyond cropping. If a feed was down at capture time, that is fine; the bar shows it.
